# Dashboard-html-css-jss

A modern and responsive financial analytics dashboard built using HTML, CSS, JavaScript, and Chart.js.

## Features
- Animated TechNova logo
- Responsive modern UI
- Interactive Line, Bar, and Pie charts
- Financial analytics visualization
- Smooth animations and hover effects
- Mobile-friendly design

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Chart.js

## Preview
This project visualizes revenue, expenses, and profit analytics through interactive charts in a clean dashboard interface.
